# Roadmap

This is a high-level view of planned direction. Dates are not commitments; priorities can change. For the latest work, see open [issues](https://github.com/YOUR_ORG/angle-hr-web/issues) and [milestones](https://github.com/YOUR_ORG/angle-hr-web/milestones) if used.

## Near term

- Hardening CI and developer experience (lint, test, build gates).
- Environment and API integration patterns for the HR platform backend.

## Medium term

- Authentication and session handling aligned with the Angle HR product.
- Core hiring workflows (roles, applicants, pipelines) as the product scope grows.
- Accessibility and internationalization (i18n) improvements.

## Longer term

- Richer analytics and reporting surfaces (where applicable to the open UI).
- Performance and observability (Web Vitals, error tracking) as traffic grows.

If you want to work on something here, open an issue to discuss approach before large refactors or new features.

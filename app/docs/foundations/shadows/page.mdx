# Shadows

Shadows come from the Figma Effects collection. They are the same in light and dark mode. Use `shadow-sm`, `shadow-md` and `shadow-lg` for elevation; the others belong to specific components.

<ShadowList />

> `shadow-slots-small` and `shadow-sm` differ only in the blur of the second layer (4px against 6px). The code keeps them apart until design decides whether they should be one.

# Icons

Open HR's icons come from Heroicons, extended with custom additions. Every icon has two styles: **Outline** for most of the interface, and **Solid** for emphasis and active states. Don't mix both styles in one component.

[Open the icon library in Figma](https://www.figma.com/design/7jCMwDng7HF5g7F3tGXf0E/Open-HR?node-id=2162-49454)

## Using an icon

`MaskIcon` draws an icon from `public/dashboard/icons` in the current text colour, so it follows the theme. A few common icons are also exported as React components from `@/components/ui/icons`.

```tsx
import { MaskIcon } from '@/components/ui/icons/mask-icon'
;<MaskIcon src="/dashboard/icons/inbox-outline.svg" size={16} />
```

Icons are decorative by default (`aria-hidden`). If an icon is the only content of a button, give the button an `aria-label`.

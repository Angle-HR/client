# Toggle

Switches a single setting on or off, and the change applies straight away. If the choice only takes effect when a form is saved, use a checkbox.

<Example name="toggle/overview" />

```tsx
import { Toggle } from '@/components/ui/selection-controls'
```

Control it with `toggled` and `onChange(next)`, or pass `defaultToggled` to let it keep its own state. It renders a `<button role="switch">`.

## Sizes

<Example name="toggle/sizes" />

| Size           | Figma name | Track | Thumb | Slides |
| -------------- | ---------- | ----- | ----- | ------ |
| `md` (default) | 20px       | 32×20 | 16px  | 12px   |
| `sm`           | 16px       | 22×14 | 10px  | 8px    |

Both have 2px padding and fully round ends. The thumb has no shadow.

## States

<ToggleStates />

Off is a 15% grey track; on is blue. The thumb is `bg/primary` (off-white in light, dark grey in dark). Hover adds a 0.5px stroke inside the track; Focus adds the same stroke plus a blue ring (see Accessibility). Disabled off has a fainter track, a 1px stroke and a grey thumb; disabled on fades to 40%. Toggling takes 50ms (Figma's ease out); the hover stroke appears instantly, as Figma has no hover transition.

**Figma oddities, copied as they are:**

- The "16px" size is 14px tall (22×14).
- The off hover and focus stroke uses `border/Transparent/light` at 16px but `border/Transparent/lighter` at 20px.

## Usage

<DoDont>
  <Guideline kind="do">
    Use it for settings that apply immediately: "Show salary on the job post".
  </Guideline>
  <Guideline kind="dont">Use it inside a form that needs saving. Use a checkbox.</Guideline>
  <Guideline kind="do">Put the label next to it and keep it short.</Guideline>
  <Guideline kind="dont">
    Write "On" or "Off" in the label. The toggle already shows that.
  </Guideline>
</DoDont>

## Accessibility

- **Keyboard:** Tab to reach it, Space or Enter to switch it. It's a `<button role="switch">` with `aria-checked`.
- **Focus:** the hover stroke plus a 1px blue ring (`bg/selection-controls/selected`, the blue the buttons use for focus), 2px outside the track. It only shows for keyboard focus, not on click.
- **Label:** pass `aria-label`, or wrap it in a `<label>` with the text.

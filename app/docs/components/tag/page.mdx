# Tag

A short coloured label for a status or category, like "Hired" or "Full-time". Tags only show information; to let people filter or pick, use a chip.

<Example name="tag/overview" />

```tsx
import { Tag } from '@/components/ui/tags'
```

Pick a `color` for the meaning, and `weight="medium"` when it needs to stand out.

## Sizes

<Example name="tag/sizes" />

| Size           | Figma name | Height      | Padding   | Radius | Text            |
| -------------- | ---------- | ----------- | --------- | ------ | --------------- |
| `lg` (default) | Large      | 20px        | 8px sides | 7px    | 13px, Body S    |
| `sm`           | Small      | 20px        | 6px sides | 7px    | 12px, Body xS   |
| `xs`           | xSmall     | 14px (hugs) | 4px × 3px | 4px    | 11px, Caption M |

Text is Regular by default, or Medium with `weight="medium"`.

## Removable

<Example name="tag/removable" />

`removable` adds a 20×20 remove button after the label, 2px away, rounded on the right. Its 14px x-mark takes the tag's text colour. On hover it fills with a 2% black (3% white in dark), fading in over 150ms (Figma's ease out). Pass `onRemove` to handle the click. Figma has no removable xSmall, so `removable` does nothing at `xs`.

## States

<TagStates />

Each colour binds `bg/tags/<colour>` and `text/tags/<colour>`. Empty is the only one with a stroke: a 1px dashed line (2px dash, 2px gap) in `border/tags/empty`, centred on the edge like Figma's.

**Figma oddities, copied as they are:**

- Empty uses `bg/non`, which is white (#171717 in dark), so it's filled, not see-through. The code had it transparent; that's now fixed.
- Small is the same 20px height as Large; only its padding and text are smaller.

## Usage

<DoDont>
  <Guideline kind="do">Keep it to one or two words: "Hired", "Remote".</Guideline>
  <Guideline kind="dont">Put a sentence in a tag, or use it as a button.</Guideline>
  <Guideline kind="do">Use the same colour for the same meaning everywhere.</Guideline>
  <Guideline kind="dont">Rely on colour alone. The label should say what it means.</Guideline>
</DoDont>

## Accessibility

- **Text:** the label is the content; screen readers read it as plain text.
- **Remove button:** a real `<button>` named "Remove" plus the tag text, e.g. "Remove Figma". Tab to it, Enter or Space to remove.
- **Focus (not in Figma):** Figma has no focus state for the remove button, so the code shows a 1px blue ring on keyboard focus, like the selection controls.

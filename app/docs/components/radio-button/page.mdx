# Radio Button

Lets people pick exactly one option from a short list. For options they can combine, use a checkbox. For a single on/off setting, use a toggle.

<Example name="radio-button/overview" />

```tsx
import { RadioButton } from '@/components/ui/selection-controls'
```

Give every radio in a group the same `name`, and control them with `checked` and `onChange`. Wrap the group in an element with `role="radiogroup"` and an `aria-label`.

## Sizes

<Example name="radio-button/sizes" />

| Size           | Area | Circle | Dot    | Label                  |
| -------------- | ---- | ------ | ------ | ---------------------- |
| `sm` (default) | 22px | 15px   | 7.63px | 13px, Body S Regular   |
| `md`           | 24px | 16px   | 7.63px | 13.8px, Body M Regular |

Figma names the sizes by their text: "13px" and "13.8px".

## Label

The label sits on the right by default, or on the left with `textPosition="left"`. With `textPosition="none"`, give it an `aria-label`. Labels are primary text, Regular, with 3px either side and no gap to the radio.

<Example name="radio-button/label-position" caption="Hover to see the round hover area." />

## States

<RadioStates />

Unselected is a 1px grey ring with no fill. Selected is a blue circle with a white dot. Hover fills the round area behind it: light grey when unselected, light blue when selected. It fades in over 100ms (Figma's ease in) and out over 100ms (ease out). Selecting and deselecting take 50ms (ease out). Disabled fades the whole radio, label included, to 30%.

**Figma oddities, copied as they are:**

- Disabled with a label: the radio is faded twice (30% inside 30%), so the circle shows at about 9% while the label is at 30%.
- Disabled and selected: a faint 1px `border/notification` ring (6% black, 6% white in dark) appears that no other state has.
- The white dot uses the primitive `color/white/white`, not a semantic token.

## Usage

<DoDont>
  <Guideline kind="do">Use it for 2 to 5 options where only one can apply.</Guideline>
  <Guideline kind="dont">
    Use it for a long list. Use a select so the list doesn't take over the page.
  </Guideline>
  <Guideline kind="do">Pick a sensible default so the group never starts empty.</Guideline>
  <Guideline kind="dont">Use a single radio on its own. Use a checkbox.</Guideline>
</DoDont>

## Accessibility

- **Keyboard:** Tab reaches the group, the arrow keys move between options. The real `<input type="radio">` is kept in the page, hidden visually.
- **Focus:** when you Tab to it, it shows its hover fill plus a 1px blue ring (`bg/selection-controls/selected`, the blue the buttons use for focus). It only appears for keyboard focus, not on click.
- **Label:** the whole row, label included, is clickable. Without a visible label, pass `aria-label`.

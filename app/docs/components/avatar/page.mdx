# Avatar

A person, company or country, shown as initials, a photo, an icon or a flag.

<Example name="avatar/overview" />

```tsx
import { Avatar, getInitials } from '@/components/ui/avatar'
```

## Sizes

| 24   | 13px, Body S    | 5px            | 17px |
| 20   | 11px, Caption M | 4px            | 14px |
| 18   | 11px, Caption M | 4px            | 13px |
| 16   | 11px, Caption M | 4px            | 12px |
| 14   | 10px, Caption S | 4px            | 10px |
| 12   | 9px, Label      | 3px            | 10px |

Initials are Medium, trimmed to their cap height so they sit in the optical centre. `circular` (the default) makes it fully round.

## Types

- **Initials** (`type="initials"`): `bg/avatar/<colour>` with letters in `text/avatar/<colour>`, and a 0.5px inside edge in `border/avatar/text` (black 4%, white 1% in dark).
- **Icon** (`type="icon"`): the same colours and edge, with a glyph. Figma's default glyph is an ellipsis; pass `icon` to use another.
- **Image** (`type="image"` or `"image-border"`): a photo. With a border it gets a 0.5px inside edge in `border/avatar/image` (black 4%, white 8% in dark).
- **Country** (`type="country"`, 12–20px): a flag. Square is a 3:2 flag (30×20 at 20px) with 3px corners (2px at 12 and 14); circular crops the flag to a circle.

`showNotification` adds a red dot at the top-left corner, 1px outside: 4px at 12–16, 5px at 18–20, 8px at 24–32 and 11px at 44.

### When an image fails

<Example name="avatar/fallback" />

Not in Figma: if the photo is missing or fails to load, the avatar shows the initials, or the icon if there are none.

## States

<AvatarColourStates />

**Figma oddities, copied as they are:**

- The notification dot sits at the top-left, not the top-right.
- The 14px square image has square corners with a border, and 3px corners without.
- Country only exists at 12–20px.
- The 14px square icon avatar's placeholder glyph is a plus; every other is an ellipsis. The glyph is a swap slot, so the code always uses the ellipsis.

**Not in Figma, kept in code:**

- The fallback to initials or the icon when an image fails.
- Country at 24px and above (a square flag box).

## Usage

<DoDont>
  <Guideline kind="do">Use `getInitials()` so names always become one or two letters.</Guideline>
  <Guideline kind="dont">Put three letters in a small avatar; they won't fit.</Guideline>
  <Guideline kind="do">Keep the same colour for the same person everywhere.</Guideline>
  <Guideline kind="dont">
    Use the colour alone to say who someone is; show the name nearby.
  </Guideline>
</DoDont>

## Accessibility

- **Decorative:** next to a visible name, pass `aria-hidden` so the name isn't read twice.
- **On its own:** pass `aria-label` with the person's name, or `alt` for a photo.
- **Flags** are labelled with the country code unless hidden.

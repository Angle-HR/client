# Selection

A field that opens a list to choose one option, or several.

<Example name="selection/overview" />

```tsx
import { InputSelection } from '@/components/ui/input-selection'
```

`InputSelection` is the labelled field with its list. `SelectionField` is the bare trigger, for places that bring their own list.

## Sizes and states

<Example name="selection/sizes" />

| Size | Height | Text           | Side padding | Corners | Icons |
| ---- | ------ | -------------- | ------------ | ------- | ----- |
| `lg` | 40px   | 14px, Body L   | 12px         | 10px    | 14px  |
| `md` | 32px   | 13.8px, Body M | 8px          | 8px     | 14px  |
| `sm` | 25px   | 13px, Body S   | 8px          | 7px     | 12px  |

The same sizes and colours as the [text input](/docs/components/text-input). The padding includes the 1px border. `InputSelection` comes in `md` and `sm`, the two heights Figma labels; `SelectionField` also has `lg`.

<SelectionStates />

- **Placeholder** (nothing chosen): grey text and prefix icon, grey chevron.
- **Hover**: a darker border, only while nothing is chosen. Fades in over 100ms, ease in.
- **Focus** (Tab to it, or the list is open): a blue border. 100ms, ease out.
- **Filled**: once something is chosen, a slightly darker border and dark prefix icon.
- **Error** (`errorText`): a pink border and red chevron.
- **Disabled**: a grey fill; text and prefix icon at 20%. The field itself isn't faded.

## Choosing several

<Example name="selection/multiple" />

<SelectionStates withSelection />

With `multiple` and `withSelection`, chosen values show as green tags inside the field, 2px apart, and the prefix icon is hidden.

**Figma oddities, copied as they are:**

- Every Figma state shows the same sample text, coloured as a value in Focus and Filled. In code the placeholder stays grey and only a chosen value is dark.
- Figma's Placeholder and Disabled variants with selection still show tags, at full colour, so a disabled field's tags aren't faded.
- The 25px labelled variants use the 32px field resized to 25px.

**Not in Figma, kept in code:**

- `searchable`: the field becomes a text box that filters the list (16px text on small screens, so iOS doesn't zoom).
- A leading visual, such as a flag, before the chosen value.
- Chips instead of tags (`selectionStyle="chip"`), a search box at the top of the list, and a footer action.

## Labels

<Example name="selection/labels" />

The label is the shared field label, as on the [text input](/docs/components/text-input#labels-and-helper-text). `required` adds Figma's red asterisk 2px after it; without it the field is optional.

## Usage

<DoDont>
  <Guideline kind="do">
    Use selection when there are more than a few options, or they won't fit as radio buttons.
  </Guideline>
  <Guideline kind="dont">Use it for two options; use radio buttons or a toggle.</Guideline>
  <Guideline kind="do">Turn on `searchable` for long lists, like countries.</Guideline>
  <Guideline kind="dont">Leave the placeholder as the only label.</Guideline>
</DoDont>

## Accessibility

- The field is a combobox: Enter and Space open the list, Escape closes it. In a searchable field, the down arrow opens it too.
- `InputSelection` links its label, and its helper or error text.
- Each tag's remove button says which value it removes.

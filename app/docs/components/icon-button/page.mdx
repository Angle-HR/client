# Icon Button

A square button that runs an action with only an icon and no visible label. Use it in toolbars, table rows and inline controls, where space is tight and the icon is universally understood.

Because there's no visible label, `aria-label` is required. If the icon could mean more than one thing, use [Button](/docs/components/button) with a label instead.

<Example name="icon-button/overview" />

```tsx
import { IconButton } from '@/components/ui/button'
```

## Variants

Icon Button has no `accent`. Its variants set the hierarchy.

<Example name="icon-button/variants" />

| Variant         | When to use                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------ |
| `primary`       | The most prominent icon action in a view, such as the main toolbar action                        |
| `secondary`     | Supporting icon actions next to a primary, or secondary toolbar controls                         |
| `tertiary`      | Low-emphasis actions: inline table controls, auxiliary actions in dense layouts                  |
| `light`         | The lowest emphasis: a grey icon with no fill in any state, such as a remove control on an image |
| `light-w-hover` | Like `light`, with a faint fill on hover and press so it reads as a target                       |
| `error`         | Destructive actions, such as delete. Red icon, light red fill on hover and press                 |

## Sizes

<Example name="icon-button/sizes" />

| Size | Box     | Icon | Padding           | Radius | When to use                                          |
| ---- | ------- | ---- | ----------------- | ------ | ---------------------------------------------------- |
| `xs` | 16×16px | 10px | 5px on every side | 4px    | Tiny inline controls, such as removing a tag or chip |
| `sm` | 24×24px | 14px | 5px on every side | 7px    | Toolbars, table rows, dense layouts                  |
| `md` | 32×32px | 14px | Icon centred      | 7px    | The default: page-level and modal actions            |

The icon is 14×14px, or 10×10px at `xs`. Pass it with its Figma frame using `MaskIcon`, as on the [Button page](/docs/components/button#with-icons), so the glyph has the same margin as in Figma.

Don't mix sizes in the same toolbar. At `xs` the tap target is far below 44px, so keep it for desktop-only, secondary controls.

## Counter badge

A 12px blue badge over the top-left corner for a count tied to the action, such as unread notifications. It shows `99+` above 99 and hides at 0. Put the count in the `aria-label` too.

## States

<IconButtonStates />

Hover fades in over 100ms and out over 100ms; press takes 50ms. `light` doesn't change at all on hover or press, as in Figma. Figma has no focus state for `light` and `light-w-hover`, but every variant shows the blue focus ring when reached by keyboard.

## Usage

<DoDont>
  <Guideline kind="do">
    Use it when the icon is universally understood: close, search, add, filter, settings.
  </Guideline>
  <Guideline kind="dont">
    Use it when the meaning could be ambiguous. Use a Button with a label.
  </Guideline>
  <Guideline kind="do">
    Name the action in `aria-label`, verb first: "Close dialog", "Filter results".
  </Guideline>
  <Guideline kind="dont">Describe the icon: "Magnifying glass", "Bin icon".</Guideline>
  <Guideline kind="do">
    Pair toolbar icon buttons with a tooltip that matches the `aria-label`.
  </Guideline>
  <Guideline kind="dont">
    Delete straight away from an `error` icon button. Ask for confirmation first.
  </Guideline>
</DoDont>

## In context

- **Toolbar:** `sm`, 8px apart. More than five or six in a row needs a separator.
- **Table row:** `tertiary`, `sm`. Reveal row actions on hover where you can.
- **On a phone:** the button can look 24px, but the tap target must be at least 44×44px. Add padding to the parent rather than stretching the button.

## Accessibility

- **Name:** `aria-label` is required and TypeScript enforces it.
- **Keyboard:** Tab and Shift+Tab reach it; Space or Enter activates it.
- **Focus:** a 2px blue ring, offset by 2px, on every variant.
- **Changing counts:** updating `aria-label` isn't announced by itself. Add a visually hidden `aria-live="polite"` region elsewhere on the page.
- **Disabled:** to keep it focusable so a tooltip can explain why, use `aria-disabled="true"` and block the click yourself.

# Avatar stack

Several people as overlapping avatars, with a "more" tile when not everyone fits.

<Example name="avatar-stack/overview" />

```tsx
import { Avatar, AvatarStack } from '@/components/ui/avatar'
```

## Overlap

<Example name="avatar-stack/density" />

Each avatar overlaps the one before it. There is no ring or gap drawn between them.

## The "more" tile

When there are more people than `maxVisible`, a round blue icon avatar with an ellipsis follows the faces, at the stack's size. Screen readers hear how many are hidden ("2 more"). `showOverflow={false}` leaves it out.

**Figma oddities, copied as they are:**

- The stacking order flips. Without the "more" tile the first face is on top; with it, each later face is on top and the tile is topmost.
- Figma's "4 avatar" with more shows 3 faces and the tile, but "2 avatar" with more shows 2 faces and the tile. In code, `maxVisible` is always the number of faces.

**Not in Figma, kept in code:**

- The tile appears only when someone is hidden, and its label says how many.

## Usage

<DoDont>
  <Guideline kind="do">Give every avatar in a stack the stack's `size`.</Guideline>
  <Guideline kind="dont">Mix sizes in one stack; the overlap is set per size.</Guideline>
  <Guideline kind="do">Name the people nearby or in a tooltip.</Guideline>
  <Guideline kind="dont">Rely on the faces alone to say who is involved.</Guideline>
</DoDont>

## Accessibility

- Label the whole stack (for example `role="img"` and `aria-label="Team: Ada, Bo, Cy"` on a wrapper) and hide the faces inside it, or give each face its own label.
- The "more" tile is announced as "N more".

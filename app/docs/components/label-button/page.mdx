# Label Button

A small chip that toggles on and off. Use it in groups, for filters, view switchers and quick-select controls. It isn't for one-off actions or submitting forms: use [Button](/docs/components/button) for those.

<Example name="label-button/overview" caption="Click a chip to toggle it." />

```tsx
import { LabelButton } from '@/components/ui/button'
```

The parent owns the state: pass `selected` and toggle it in `onClick`. Whether one or several chips can be on at once is up to the parent too.

## With icons

Icons go before (`iconLeft`) or after (`iconRight`) the label at 14×14px. Only add them when they make the label quicker to scan.

## Accessibility

- **Toggle state:** `aria-pressed` mirrors `selected`. Wrap the group in an element with `role="group"` and an `aria-label`.
- **Tabs:** if the group behaves like tabs, use the Tabs component instead.
- **Focus:** a blue border, as in Figma. The label is always visible, so no `aria-label` is needed.

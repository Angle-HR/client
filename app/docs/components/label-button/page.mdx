# Label Button

A small chip that switches on and off. Use a group of them for filters, view switchers and quick picks. For one-off actions or submitting a form, use [Button](/docs/components/button).

<Example name="label-button/overview" caption="Click a chip to switch it." />

```tsx
import { LabelButton } from '@/components/ui/button'
```

The parent keeps the state: pass `selected` and flip it in `onClick`. The parent also decides whether one chip or several can be on at once.

## Anatomy

| Part      | Spec                                                          |
| --------- | ------------------------------------------------------------- |
| Container | 24px high, 1px border, 7px radius                             |
| Spacing   | 8px from the outer edge, 4px between icon and label           |
| Label     | Inter Medium, 13px                                            |
| Icons     | Optional, 14×14px, before (`iconLeft`) or after (`iconRight`) |

## Accessibility

- **State:** `aria-pressed` follows `selected`. Wrap the group in `role="group"` with an `aria-label`.
- **Tabs:** if the group switches between panels, use Tabs instead.
- **Focus:** a blue border. The label is always visible, so no `aria-label` is needed.

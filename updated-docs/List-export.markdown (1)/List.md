# List

List Item components are the rows used in dropdowns, menus, selection panels, and scrollable lists across Open HR.

## Components

| Component | Use for |
|-----------|---------|
| [List Item Default](./List/List%20Item%20Default.md) | A plain clickable row, with an optional danger variant |
| [List Item With Icon](./List/List%20Item%20With%20Icon.md) | A row with a trailing informational/status icon |
| [List Item Multi-Select](./List/List%20Item%20Multi-Select.md) | Checkbox rows for multi-select dropdowns and filters |
| [List Item Selected](./List/List%20Item%20Selected.md) | Single-select rows with a trailing check on the active option |
| [List Item Button](./List/List%20Item%20Button.md) | A row with a trailing hover-reveal or always-visible action button |
| [List Item Toggle](./List/List%20Item%20Toggle.md) | A row with a trailing toggle switch for inline settings |
| [List Item Location](./List/List%20Item%20Location.md) | Address suggestion rows with a radio button (autocomplete) |

## Sub-components

| Sub-component | Role |
|---------------|------|
| [List Item Content](./List/List%20Item%20Content.md) | The shared icon + main text + sub-text block inside every row variant |
| [List Item Picker](./List/List%20Item%20Picker%20(sub-component).md) | Card-style selectable option with icon, title, and optional sub-text |
| [Scrollbar](./List/Scrollbar%20(sub-component).md) | Custom scrollbar styling for scrollable list containers |
